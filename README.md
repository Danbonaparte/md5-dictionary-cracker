# MD5 Dictionary Cracker (Bash)

A simple, lightweight Bash script designed to perform dictionary attacks against MD5 hashes for educational and cybersecurity testing purposes in a Linux environment.

## Features
- Interactive prompt for target MD5 hash input
- Automated wordlist iteration and comparison
- Time and attempt tracking
